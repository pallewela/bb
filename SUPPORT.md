# Getting help with bb

- **Questions and how-to:** open an [issue](https://github.com/pallewela/bb/issues/new) and say it's
  a question. Check the [README](README.md), `bb <command> --help` and [PRD.md](PRD.md) (which lists
  how each command differs from `gh`) first.
- **Bugs:** open an [issue](https://github.com/pallewela/bb/issues/new) with the output of
  `bb --version`, your OS, the exact command, what you expected, and what happened. Remove tokens,
  emails and private repository names from pasted output. `bb auth status` without `-t` is safe to
  paste.
- **Feature requests:** open an issue describing the use case. If `gh` has the equivalent, link to
  it.
- **Security vulnerabilities:** don't open an issue. Report them privately as described in
  [SECURITY.md](SECURITY.md).

Problems with Bitbucket Cloud itself (outages, API behavior, account or token problems) are for
[Atlassian Support](https://support.atlassian.com/bitbucket-cloud/), not this project.

`bb` is maintained in spare time, so replies may take a few days.
